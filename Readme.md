# Machine Learning Practice | Data Science

A beginner-level Machine Learning learning repository documenting my hands-on practice with data preprocessing, supervised learning algorithms, and hyperparameter tuning using Python and Google Colab.

I started learning Data Science recently and am building my understanding step by step by implementing algorithms, exploring datasets, and practicing the workflow used to prepare data and train ML models.

> **Current focus:** Supervised Machine Learning and model tuning. This repository is a learning portfolio, not a claim of advanced or production-level ML expertise.

## 📚 Topics Covered

### 1. Classification

Practice notebooks for predicting categories or class labels.

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier
- Random Forest Classifier
- Extra Trees Classifier
- AdaBoost Classifier
- Gaussian Naive Bayes
- Multinomial Naive Bayes
- Bernoulli Naive Bayes

### 2. Regression

Practice notebooks for predicting numerical values.

- Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Decision Tree Regressor
- Random Forest Regressor

### 3. Data Preprocessing

Preparing data before applying machine learning algorithms.

- Encoding categorical features
- Label, ordinal, and one-hot encoding concepts
- Exploring skewed distributions
- Applying `log1p` transformations

### 4. Hyperparameter Tuning

A dedicated notebook for learning how model settings can be adjusted to explore and improve model behaviour.

- Hyperparameter tuning concepts
- Tuning approaches demonstrated in the notebook
- Practice with regression and classification algorithms

## 🔄 My Learning Workflow

My practice generally follows these steps, depending on the notebook:

1. Understand the dataset and the prediction task.
2. Inspect the data and perform exploratory analysis where needed.
3. Prepare features through cleaning or encoding where needed.
4. Select a suitable classification or regression algorithm.
5. Train the model and examine its behaviour.
6. Practice hyperparameter tuning as I learn model configuration.

## 🎯 Learning Goals

- Understand what different supervised ML algorithms do.
- Learn when and why to choose classification versus regression.
- Practice preparing real or example datasets for model training.
- Become more comfortable implementing models with scikit-learn.
- Understand the purpose of hyperparameter tuning.
- Build a foundation for further Data Science learning.
